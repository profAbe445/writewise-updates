# WriteWise updates

Release channel for **WriteWise**, the writing assistant add-in for Microsoft Word
(grammar, paraphrasing, tone, readability and summaries).

- **Download the latest installer:** see `latest.json` → `file`, in the [`releases/`](releases/) folder.
- Installed copies of WriteWise check `latest.json` automatically and install new versions in the background.
- Every release is signed. WriteWise refuses any update whose Ed25519 signature or SHA-256 checksum doesn't match.

Requirements: Windows 10/11 (64-bit) and Word 2016 or later / Microsoft 365.
